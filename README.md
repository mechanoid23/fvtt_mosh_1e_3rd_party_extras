# Mothership 1e — 3rd Party Extras

A FoundryVTT module collecting third-party community content for the **Mothership 1e** TTRPG system (`mosh`).

## Installation

Paste the manifest URL into Foundry's **Add-on Modules → Install Module** field:

```
https://raw.githubusercontent.com/mechanoid23/fvtt_mosh_1e_3rd_party_extras/main/module.json
```

## Contents

### Gear For A Spacefarer

Equipment available from the **Cadwal Trade Depot** — a fleet of merchant ships that never sell while docked, operating out of orbit to avoid local tax laws. The **CTD Lucille** is a C Class Port with a mostly android staff.

| Compendium | Type | Description |
|---|---|---|
| Gear For A Spacefarer | Journal | Introduction, entry requirements, and item tables by category |
| Gear For A Spacefarer - Contracts | RollTable | 1d10 contract table for the CTD Lucille |
| Gear For A Spacefarer - Items | Item | 26 items across six categories |

**Item categories:** Utility · Leisure · Medical · Drug · Electronic · Misc

---

### Disciples of a Cracked Skull

Improvised and unconventional weapons.

| Compendium | Type | Description |
|---|---|---|
| Disciples of a Cracked Skull | RollTable | Wounds: Chemical Weapons (1d10-1) |
| Disciples of a Cracked Skull | Item | 12 weapons with custom artwork |
| Disciples of a Cracked Skull | Journal | Weapon reference table |

**Weapons:** Chainsaw · Molotov Cocktail · Chem Sprayer · Lasso · Rioter's Shield · Warp Core Grenade · Pressure Bomb · Beartrap · Stink Bomb · Ice Pick · Slungshot · Firework Launcher
